# CHATGPT_PROJECT.md

This repository belongs to the ChatGPT Project named `jng - the music setup`.

The canonical repository for that project is `sempervent/music-rig`.

## How ChatGPT and Codex should use this repository

- Treat this repository as the authoritative durable record of the rig.
- Read the existing documentation before answering, planning changes, or editing files.
- Use repository evidence first when describing routing, equipment, channel assignments, troubleshooting history, and unresolved decisions.
- Update related documentation together when the physical setup changes instead of changing only one representation.
- Do not invent missing facts. If the repository does not establish something, leave it unknown or mark it as an open question.
- Distinguish CURRENT signal-path membership from OWNED inventory and from PLANNED / EXPERIMENT routes.
- Wishlist entries are speculative. TODO entries are accepted work. Open questions are unresolved facts.
