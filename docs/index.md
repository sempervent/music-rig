# Music Rig

This is the living map for the studio: instruments, mixer, interface, pedals, loopers, MIDI, Ableton tracks, and known failure modes.

The design goal is not purity. It is controllable chaos: clean captures available at all times, wet loops available on demand, KAOSS sampling fed from the mixer monitor path, and enough documentation that future changes do not turn the room into a copper snake nest.

## Core principles

1. **Always preserve clean signals where possible.**  
   The TASCAM gets clean mixer, miniKORG, guitar, bass, and KAOSS channels separately.

2. **Treat the AUX SEND as the creative wet loop.**  
   Instruments can be sent into the RC-1, pedal chains, and stereo return without destroying the clean path.

3. **Keep KAOSS Replay as its own captured instrument.**  
   KAOSS output lands on TASCAM 9/10.

4. **Document every weird failure.**  
   The rig is complicated enough that solved problems need a tombstone.
