## Clip naming convention

Use this pattern:

```text
YYYY-MM-DD_source_device_bpm_key_take-description
```

Examples:

```text
2026-07-13_bass_kaoss_92bpm_Am_take01_swamp-pulse
2026-07-13_privia_rc1_110bpm_Dm_take03_half-lit-loop
```
